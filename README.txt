# ScrollHub — PWA balíček pro Android

Obsah:
- `index.html` — aplikace ScrollHub
- `manifest.webmanifest` — instalační údaje a název aplikace
- `sw.js` — základní service worker
- `icon.svg` — ikona ScrollHub

## Postup
1. Nahraj všechny čtyři soubory do kořene veřejného GitHub repozitáře.
2. Zapni GitHub Pages pro větev `main` a složku `/(root)`.
3. Otevři veřejnou HTTPS adresu aplikace v PWABuilderu a vytvoř Android balíček, pokud je pro danou cestu dostupný bezplatný výstup.

Poznámka: ukázková videa se načítají z externích URL. Nahrání videa je zatím pouze místní náhled, nikoliv veřejné publikování.
